One Letter: Coffee or Tea — this program writes a single letter, A for coffee, to /output/entry.txt. A is the bolder, more vivid choice: dark, bitter, energizing, the third black cup that wakes the day. Tea is gentle; coffee is alive.

The output is exactly one byte — the letter `A` with no newline, no explanation, nothing else.

## Run it

```sh
python3 main.py
```
